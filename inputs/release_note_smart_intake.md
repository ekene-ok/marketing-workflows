# Release note: Smart Intake now reads bank statements

What changed: Smart Intake now recognises bank statements in client uploads and extracts transactions into a review screen. Staff confirm each extraction before it is saved.
Who benefits: firms that receive monthly bank statements from bookkeeping clients
Availability: all customers; Smart Intake add-on required ($18 per user per month), with a 30-day free trial for firms that do not have it

Segments for in-app messages:
1. Core customers without Smart Intake (offer the free trial)
2. Current Smart Intake users (announce the new capability)
